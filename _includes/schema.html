{%- comment -%} JSON-LD structured data. A single Person node with a stable @id (/#person) is emitted on every page so Google and LLM retrieval layers resolve every page to the same entity rather than to a dozen unconnected pages. The WebSite node is emitted everywhere too so that isPartOf never dangles. /aboutme is typed as a ProfilePage; posts as BlogPosting; everything else as WebPage. Consumes `title` and `description` (raw, unescaped) from head.html. {%- endcomment -%} {%- assign person_id = '/#person' | absolute_url -%} {%- assign site_id = '/#website' | absolute_url -%} {%- assign page_id = page.url | absolute_url | append: '#page' -%}
